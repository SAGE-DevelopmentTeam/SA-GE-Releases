# SA:GE Official Releases

Official public release repository for **SA:GE** (*Stardew Authoring : Game Editor*).

## 🚀 Latest Release: SA:GE V5.2.0

* **Release Tag**: [`v5.2.0`](https://github.com/SAGE-DevelopmentTeam/SA-GE-Releases/releases/tag/v5.2.0)
* **Date**: September 22, 2026
* **Package**: [`SA-GE-5.2.0-win-x64.zip`](https://github.com/SAGE-DevelopmentTeam/SA-GE-Releases/releases/download/v5.2.0/SA-GE-5.2.0-win-x64.zip)
* **Target Platforms**: Windows 10 / 11 (64-bit)
* **Game Version**: Stardew Valley 1.6+ (SMAPI 4.0+)
* **SHA-256 Checksum**: `41576b43a6b09d8859405ae847621b77b675274a9f5c072e27904aa905dd3aa0`

### Highlights
* **Event Studio 2.0**: Visual Scene Director with drag-to-direct movement trajectories, crisp subpixel-aligned canvas overlays, live dialogue previews, natural-language action translation, and real-time conflict detection.
* **Stardew Valley 1.6 Modernization**: Full support for Qualified Item Routing (`Data/Objects`, `Data/BigCraftables`, `Data/Weapons`), visual Recipe Studio with 6-token string serialization, multi-token mail attachments, and canonical trigger actions.
* **Manifest Disk Authority**: `manifest.json` is the sole source of truth on disk for mod metadata and dependencies, eliminating project drift.
* **Cross-System Cohesion & Reference Safety**: Live dependency reference validation across Quests, Recipes, Items, Mail, Maps, Characters, and Tilesheets.
* **Hardened Release Packaging Hygiene**: Automated verification and clean, optimized distribution in public binaries.
