# SA:GE Official Releases

Official public release repository for **SA:GE** (*Stardew Authoring : Game Editor*).

## 🚀 Latest Release: SA:GE V5.0.0

* **Release Tag**: [`v5.0.0`](https://github.com/SAGE-DevelopmentTeam/SA-GE-Releases/releases/tag/v5.0.0)
* **Date**: September 18, 2026
* **Package**: [`SA-GE-5.0.0-win-x64.zip`](https://github.com/SAGE-DevelopmentTeam/SA-GE-Releases/releases/download/v5.0.0/SA-GE-5.0.0-win-x64.zip)
* **Target Platforms**: Windows 10 / 11 (64-bit)
* **Game Version**: Stardew Valley 1.6+ (SMAPI 4.0+)

### Highlights
* **Character AI Dialogue Studio**: Context-rich prompt synthesis, authoritative fact hierarchy, romance/marriage dialogue separation, portrait token validation, and live in-game dialogue preview.
* **100% Privacy-First**: Free-first prompt compiler workflow for ChatGPT, Claude, Gemini, or local models. Zero subscriptions, zero telemetry.
* **Real-Time Co-Op & Studio Polish**: Real-time collaborative modding, visual map editing, item creation, cutscene directing, and quest management.
